## 🚀 Run Locally

```bash
git clone https://github.com/MARKMWENDA-PIXEL/nexus-creative.git
cd nexus-creative
cd backend && npm install
cp .env.example .env
npm run db:init
npm run dev
```

Visit **http://localhost:3000**

---

## 🐳 Run with Docker

```bash
docker compose up --build
```
